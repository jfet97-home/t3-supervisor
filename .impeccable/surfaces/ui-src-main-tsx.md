# Dashboard workspace

Mode: Operate. The operator scans current supervision across projects, then opens the exact conversation to understand and intervene.

## Direction contract

THESIS: Make the state of work legible before asking the operator to navigate. An attention-first overview opens the same persistent conversation workspace used for evidence and controls.

OWN-WORLD: Transport interchange wayfinding contributes a midnight-indigo navigation field, cool-white work areas, teal selection and a precise system sans. Compact aligned rows carry real objective, assessment, status and freshness. Amber and red mean a real issue.

STORY: See what requires inspection, read why, enter the exact context and act with the existing confirmed controls. Native activity, agreed plan and semantic assessment remain distinct.

CONVERSATION STATUS: The existing Task surface also shows authoritative Following or availability text and a native understanding/draft disclosure. Following is a current mode, independent of chronology and agreement. Engaged mode names its participation explicitly, separately from agreement and execution progress. Stale, stopped, uncertain and unavailable reads never claim fresh following. Background status changes preserve focus and do not announce interstitial refresh noise.

FIRST VIEWPORT: A narrow persistent left rail names Home, Projects, Activity and Settings; Guide sits below. A compact environment header stays visible. Home leads with current attention reasons and a searchable work list; project and conversation views keep their context above the work. A conversation has Task, Supervision and Connected work views, on the title band. In Task, the task statement and a semantic outcome strip with the current steps lead, then the one connected step tree, whose first step is visible in the first viewport; the actual Supervisor proposal and agent acceptance occupy a tinted side region, stated once, with records and provenance disclosed. Statuses come only from the current workflow; a pending proposal is listed as changes and never resets them. Evidence and earlier records sit in one disclosure. Checkout selection stays in Definitions. No percentage completion or invented dialogue.

FORM: Extend the existing Operate system with a connected workflow track and a separate agreement region. This section-level extension did not roll a new visual world; the earlier seed reference was inherited history and is not claimed as verified provenance for this work. GitHub Actions, Carbon, GOV.UK and Linear supplied concrete interaction and hierarchy references. No approved raster comp or new image asset is involved.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

OPERATE CORRECTION: Project entry opens the paged conversation list, with explicit list Back and retained query/page/scroll. Definitions group actual folders and native branch facts, show bounded catalog/detail and template topology, and edit the shared folder index in its own view. Native icon-plus-cue help and entity disclosures keep one compact boundary. Global/project/connection statuses stay distinct and text-labelled in the persistent header.
